# 第一版现状与待办

更新日期：2026-11-02

## 当前结论

本地首版骨架已完成，示例流程可用；真实会议到滴答任务的完整链路尚未验收。当前是固定工作流，不是多智能体。

## 待办（按优先级）

1. **腾讯真实转写验收**：会议列表、选择导入、录制定位与转写字段/分页适配已完成；当前最近会议无云录制，需使用有录制转写的真实会议验收。
2. **真实模型联调**：验证已配置模型的连接、JSON 输出和提取质量，重点检查证据、负责人及相对日期。
3. **滴答闭环验收**：通过网页人工确认后，写入一条测试任务，核对目标清单、议题分组、日期及任务内容，确认不附加原文证据。
4. **观测验证**：确认 LangSmith 能收到节点耗时和 token 用量。
5. **整体验收**：用一场真实会议走通“选会议 → 拉转写 → 分析 → 修改确认 → 同步”，记录问题并补齐必要回归测试。

## 首版边界

仅面向本机单用户、手动触发；不做实时录音、自动分析、跨会议追踪或多智能体。滴答 MCP 当前使用 Bearer，尚未实现客户端 OAuth 登录流程。
